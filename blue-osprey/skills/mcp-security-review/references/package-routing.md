## Required files

Read these files completely for every assessment:

1. `README.md` — package status, operating tracks, review paths, and decision rule.
2. `mcp-server-evaluation-checklist.md` — evidence record, hard gates, conditional triggers, decision, and retirement requirements.
3. `mcp-security-assessment-report-template.md` — required assessment report structure and decision fields.

Read these files when the task requires their subject:

- `mcp-secure-use-guidance.md` — control interpretation, evidence by path, implementation guidance, change, and retirement.
- `mcp-position-paper.md` — the organization's position, non-negotiable rules, and leadership-facing rationale.
- `mcp-security-standard-candidate.md` — proposed normative requirements. Identify it as a candidate until approval is verified.
- `mcp-ai-gateway-near-future-consideration.md` — current-state gateway limits and future gateway suitability.

## Output use

Keep the official package generic. Store completed reviews outside the package unless the user explicitly directs otherwise.
